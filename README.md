# SpeakUp 120 — Final Human Communication Website

This version uses a polished pastel productivity-dashboard interface inspired by the approved visual direction.

Core principle: sound human, not AI.

Includes:
- 120-day progressive communication program
- natural human-language standard
- speaking and recording practice
- workplace, client-call, difficult-situation and networking practice
- writing/proofreading and vocabulary
- negotiation mastery with expert study material
- feedback prompts across practice areas
- reading lab using short public-domain classic-novel excerpts
- progress, calendar, notes and local browser persistence
- responsive desktop/mobile layout

The novel reading lab uses short excerpts and original practice prompts rather than reproducing modern copyrighted books.
