# SpeakUp 120 — Final Communication Coach

Includes the complete 120-day communication curriculum plus a Negotiation Mastery Lab.

Negotiation content is grounded in:
- William Ury / Harvard Program on Negotiation
- Chris Voss / Black Swan Group
- Alexandra Carter / Ask For More

The site includes BATNA, interests vs. positions, anchoring, objective criteria,
calibrated questions, silence, Positive No, workplace negotiation drills, and a
curated YouTube study sequence.

Study method: watch one expert lesson, extract one technique, practise it aloud,
then apply it to a workplace/legal scenario.

This is a standalone local website and does not claim to perform true AI speech
analysis. ChatGPT can be used alongside it for deeper feedback on real answers.
